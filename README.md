# Yigora

Asistente inteligente de ventas para vendedores que atienden clientes por WhatsApp Web.
Lee la conversación del día, busca en el inventario de la empresa y sugiere respuestas en el idioma del
cliente. **Nunca envía mensajes:** el vendedor siempre decide.

> Proyecto privado. Acceso solo por invitación.
